# Methods (baseline)

This project evaluates cooperative dark fleet detection using temporal co‑movement graphs derived from daily MMSI grid data. We construct an undirected temporal graph where nodes are vessels (MMSI) and edges connect vessels observed within a distance threshold during the same day. To keep computation tractable, we cap the number of rows per day and sample a fixed number of daily files per year. The resulting edge list is deduplicated and used for link‑prediction experiments.

For node features, we aggregate sea‑surface temperature (SST) values from the vectorized extraction outputs. We compute daily per‑vessel summaries (mean, standard deviation, min/max, missing rate), spatial summaries (mean latitude/longitude), and simple movement features (total distance traveled, speed statistics, and stop rate). We also compute temporal interaction features from the training period (interaction count, unique partners, recency in days, mean gap). These features are joined by MMSI and used as optional inputs to feature‑augmented baselines, including temporal GNN inputs (degree concatenated with temporal interaction features). We additionally test an edge‑level temporal baseline that uses pair recency and frequency features.

Baselines include heuristic link predictors (common neighbors, Jaccard, Adamic‑Adar), a lightweight linear GAE analogue via low‑rank adjacency factorization (truncated SVD), a node2vec/DeepWalk‑style random‑walk embedding baseline, temporal GNN baselines (TGCN and GConvGRU/LSTM variants trained on time buckets), and a minimal temporal GNN‑lite (TGN‑style) model that updates node memories over time. We also run a simple GAE‑style prototype (SVD with optional features) and a minimal PyTorch GAE prototype with learned embeddings and a dot‑product decoder to validate the end‑to‑end pipeline on year‑sliced and multi‑year graphs. We evaluate link prediction using train/test edge splits with matched negative sampling (random splits and time‑based splits), reporting ROC AUC and average precision across multiple random seeds for robustness.

The official baseline is the multi‑seed linear GAE without SST features, using the capped multi‑year edge list and fixed hyperparameters. Feature‑augmented variants and Torch/GAE prototypes are treated as ablation studies.
